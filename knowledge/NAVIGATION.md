# Navigation model

status: draft

A primary reel connects open water with the cave guideline when required. A primary tie-off provides an open-water reference where direct ascent is possible. A secondary tie-off secures the route and reduces the consequences of a disturbed first attachment. Subsequent placement must avoid line traps, slack, abrasion and interference. Learn actual placement with an instructor, not from a schematic.

Mainline denotes the principal established guideline for the chosen route. A jump connects to another line/route using a temporary continuous connection; a gap bridges a discontinuity between line ends. A T intersection is an existing connected branch: continuous line does not remove the need to identify the return direction. A circuit returns by a loop; a traverse exits at a different opening. Both require training and explicit route/gas planning; a shorter-looking line is not permission to change the plan.

System arrows are directional markers in a local system, not a universal guarantee of the team's proven exit. A cookie is non-directional: placement and the agreed protocol carry meaning. A REM is a personal directional exit reference; the longer end indicates the chosen exit under the taught convention. Personal markers must be identifiable and their meaning agreed before diving. A name on a marker alone does not prove that it is temporary: permanent exploration markers may be personalized.

The course's fictional cases use a personal exit-side marker at each decision and an owned temporary line for a jump. State this convention in each diagram rather than claiming a universal regional standard. A lone cookie is not a directional anchor for a jump. Follow the trained local installation protocol; do not improvise anchor geometry from text. Never use or remove another team's temporary connection as your own.

Team-marker and individual-marker conventions both require every diver to understand the route. Individual markers add personal participation but cannot compensate for an unbriefed protocol. Conflicting information must be resolved using the proven route, personal references, orientation and team communication; do not average arrows or make an unsupported guess. Local conventions vary. Navigation knowledge here does not validate a real cave route.

Touch identification, zero-visibility line following, jump installation and line recovery require instructor-supervised practical assessment. A diagram establishes relationships, not distances, line tension, placement suitability or accessibility of an exit.
