# Independent course design

status: draft
date: 2026-11-05

The course uses a sixteen-scene sequence with seven dedicated gas modules and a final integrated review. The target learner is preparing for or revising practical cave training. English subject text supports teaching in the learner's language while retaining consistent technical terminology.

Subject content and exercises are original prose. The course contains its own teaching and answers; no external repository, installed skill or platform-specific interface is needed to deliver it. Numerical approximations are explicit, and arithmetic checks are separate from subject review.

The baseline matching method is a common inbound litre budget from the smallest inventory. More detailed reserve-demand reasoning is labelled separately. Rounding acts conservatively at specified 5 bar increments. No aggregate inventory model asserts per-cylinder availability after failure.

The course distinguishes theory evidence from practical competency. Optional reveal permits progress, but unresolved critical objectives prevent a theory-completion statement. Practical assessment remains pending instructor observation.

All subject material begins as draft. GitHub pull requests provide review history. The repository uses draft and verified statuses without external citation fields or a separate reviewer registry.
