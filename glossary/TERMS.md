# Canonical terminology

status: draft

Retain these English terms in every teaching language; explain their meaning in the learner's language.

| Term | Meaning and distinction |
|---|---|
| overhead environment | Direct ascent is physically obstructed. |
| cavern / cave | Distinct training/environment categories; daylight alone does not establish applicable limits. |
| mainline | Established principal guideline on the chosen route. |
| primary reel | Team reel used to establish the required route connection from open water. |
| primary tie-off | Initial open-water attachment/reference where direct ascent is possible. |
| secondary tie-off | Subsequent security/reference that limits consequences of disturbance. |
| guideline | Physical line reference; continuity and direction are different properties. |
| line trap | Placement that can lead the line/diver into an unsuitable or impassable space. |
| jump | Temporary connection to another line/route, with continuity and agreed exit reference. |
| gap | Discontinuity between line ends requiring a temporary connection. |
| T intersection | Connected branch that still requires return-direction decisions. |
| circuit | A route forming a loop. |
| traverse | A route exiting through a different opening. |
| system arrow | Directional system information; not proof of this team's accessible exit. |
| cookie | Non-directional personal marker whose meaning depends on placement/protocol. |
| REM | Referencing Exit Marker; personal directional reference under the agreed convention. |
| water capacity | Internal cylinder size in L, distinct from surface-equivalent gas L. |
| free-gas volume | Approximate surface-equivalent gas quantity in L for classroom calculations. |
| turn pressure | Individual pressure threshold requiring the team to end penetration, subject to earlier limits. |
| rule of thirds | Stated maximum inbound fraction of one third in the simplified allocation model. |
| rule of sixths | Stated maximum inbound fraction of one sixth, not a remaining-gas fraction. |
| gas matching | Aligning team penetration allocations in free-gas volume before converting to individual pressure drops. |
| RMV | Surface-equivalent consumption in L/min; not raw depth pressure loss. |
| SAC | Ambiguous usage; explicitly identify surface-normalized bar/min or surface-equivalent L/min. |
| ambient pressure | Absolute surrounding pressure; sea-level approximation 1+d/10 bar. |
| ppO2 | Oxygen fraction times ambient absolute pressure. |
| MOD | Maximum operating depth for stipulated gas/oxygen limits; other constraints may be shallower. |
| NDL | Modelled remaining no-decompression time; not cave time. |
| TTS | Modelled ascent and required-stop time; excludes horizontal cave travel. |
| GTR | Device gas-time estimate under its assumptions; not a penetration allowance. |
| CNS | Modelled central nervous system oxygen exposure indicator, not a toxicity diagnosis. |
| lost line | Diver lacks the known line reference. |
| lost diver | Team member is missing; distinct from a lost-line situation. |
| touch contact | Trained tactile team communication/control when visual communication is inadequate. |
| minimum/emergency gas | Scenario-specific gas requirement, not automatically equivalent to a fraction reserve. |
