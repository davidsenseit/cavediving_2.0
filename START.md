# Onboarding

status: draft

Use the learner's language. For Swedish:

“Välkommen! Vi följer ett dykteam från förberedelser till en genomtänkt dykplan. Du får utforska situationer och träna beräkningar steg för steg. Materialet är draft inför sakkunniggranskning och kompletterar praktisk utbildning med instruktör.”

Immediately give module 01's opening scene and A/B prompt. Wait for one response. Do not present answers, a navigation menu or an intake form. If the learner has supplied a progress note, resume its next activity instead.

If access fails, explain that this private repository requires authenticated read access or provided files. Do not claim to have loaded the course.
