# Course route

status: draft

| Module | Goal | Objective |
|---|---|---|
| [01 — The exit is part of every decision](modules/01.md) | Explain why an overhead changes every limit. | SAF-01 |
| [02 — Equipment as a working system](modules/02.md) | Identify useful redundancy and equipment dependencies. | EQP-01 |
| [03 — Control protects visibility](modules/03.md) | Connect buoyancy, trim and propulsion to exit conditions. | CTL-01 |
| [04 — Continuity before complexity](modules/04.md) | Distinguish line continuity from knowledge of exit direction. | NAV-01 |
| [05 — Whose exit does that marker indicate?](modules/05.md) | Interpret markers and explain a proven return route. | NAV-02 |
| [06 — From cylinder size to gas inventory](modules/06.md) | Convert between water capacity, pressure and free-gas litres. | GAS-01 |
| [07 — Thirds, sixths and a readable turn pressure](modules/07.md) | Apply a stated fraction and round conservatively. | GAS-02 |
| [08 — Matching equal equipment](modules/08.md) | Calculate equal-volume, equal-pressure team thresholds. | GAS-03 |
| [09 — Same cylinders, different pressures](modules/09.md) | Match equal capacities with unequal starting pressures. | GAS-04 |
| [10 — Different capacities, different pressures](modules/10.md) | Match gas in litres and identify limits of aggregate supply. | GAS-05 |
| [11 — Consumption, depth and time](modules/11.md) | Convert measured pressure use into RMV and predict demand. | GAS-06 |
| [12 — Does the donor actually have enough?](modules/12.md) | Test explicit shared-exit demand against either donor. | GAS-07 |
| [13 — Gas choice and physiological limits](modules/13.md) | Separate oxygen, inert-gas and decompression constraints. | PHY-01 |
| [14 — Recognising escalation and choosing an exit](modules/14.md) | Distinguish emergency problems and explain trained priorities. | EMG-01 |
| [15 — Read the computer in context](modules/15.md) | Distinguish displayed ascent estimates from cave-exit obligations. | INS-01 |
| [16 — Build and challenge the team plan](modules/16.md) | Integrate limits, route, gas and practical boundaries. | INT-01 |

All modules include full teaching, a worked application, a misconception correction, a callback, a visual/text equivalent and two independent activities. The final assessment uses fresh cases. Practical skills remain subject to instructor assessment.
